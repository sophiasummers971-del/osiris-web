## Recommended first staging integration

Choose **one synthetic tenant, one database-local synthetic append operation**, using generated approval/contract credentials and an independently protected test epoch authority/checkpoint. Do not start with email, arbitrary HTTP, AI, Storage signed URLs or the existing production case/audit tables.

1. Review the operation matrix, signing/enrollment and recovery protocol with an independent person. Pin the exact source/build/config and approve only the declared staging scope.
2. In separately authorized isolated staging, give the adapter a non-owner, non-BYPASSRLS role with only EXECUTE on one reviewed fixed-search_path effect function. It has no arbitrary SQL, table mutation, network-extension, scheduling or production permissions. Use primary, uncached authorization state.
3. Establish a **resource-side fence protocol**: DB transaction checks database incarnation/current resource fence, exact operation hash/IDs/tenant/approval, consumed identity and budget while appending effect/audit. Explain how external epoch transitions serialize with the DB fence and drain/quarantine in-flight work. “Check DO then write DB” alone is not accepted as proof.
4. Keep agents incapable of choosing keys, runner, tools, target URLs, registry or provider credentials. A typed request reaches only the fixed actuator; front door, cron and alternative ingress have no bypass capability.
5. Retain intent/outcome and independent checkpoint records. Crash or lost acknowledgment creates UNKNOWN/QUARANTINED. Recovery requires independent outcome/termination reconciliation plus fresh approval and fresh identities; never automatic retry/replacement.
6. Observe a disposable process tree from outside the worker. Confirm denied operations never reach the adapter and authenticated violations revoke/stop the full tree. No unconfirmed stop can release a claim.

Acceptance evidence must show: zero unapproved adapter effects; exactly one winner among concurrent independent supervisors; forged identity/receipt/tenant/plan/target rejection; direct DB/RPC/alternate route denial; stale epoch at the **effect boundary**; coherent store/witness rollback denied by external authority; audit/authority/checkpoint outage fail-closed; clock rollback, worker crash, split brain and uncertain commit quarantined; process-tree death independently observed; no late callback or automatic retry/replacement. Capture exact artifacts, role grants, effect rows using synthetic content, authority/DB fence histories and independent observer signatures.

The reviewer must assess these traces against #54 T01–T14 and explicitly reject unsupported claims. Passing existing 324 synthetic tests and repository CI is regression evidence only. No current real path is certified as production-mediated; quota, live credentials/scopes, custody, root recovery and human independence remain AMBER until separately evidenced.
