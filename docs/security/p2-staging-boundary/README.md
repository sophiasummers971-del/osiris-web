## Deliberately unresolved guarantees

Before hosted work, owners must authorize the exact resources and independent reviewers must resolve the checklist. The trusted registrar, actuator, fence controller, host, time service and restore quarantine are part of the proposed trust boundary. A compromised privileged registrar/DB administrator is not defeated by SQL role names or signatures alone. No claim is made that Supabase managed defaults permit the proposed confinement without further work.

There is no distributed transaction across authority, checkpoint and database. Resource fencing orders effects against **resource freeze**, not instant physical-time revocation at a remote authority. Pre-effect evidence failure denies dispatch; a later outage can leave an already accepted effect uncertain. Coherent rollback of all trusted state, invisible online DB restore, unprotected host/custody, or missing independent recovery truth remain blockers. See the explicit failure/restore contract before interpreting any test as evidence.
